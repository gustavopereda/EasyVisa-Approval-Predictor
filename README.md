# EasyVisa – Visa Approval Classification 

## Overview
Built ensemble classification models to predict the approval outcome of visa applications and assist legal teams in screening candidates.

## Key Metrics
- Perfect classification on training set (100%)*
- Important features: Education, Experience, Wage Type, Country of Origin

## Tools Used
- Python (Scikit-learn, XGBoost, SMOTE)
- Classification Metrics (F1 Score, Accuracy, Recall)
- Jupyter Notebook

## Deliverables
- Balanced datasets and engineered features
- Model training and evaluation
- Feature importance analysis

## Note
*Overfitting suspected — future improvement involves regularization and real-world validation.

## Recommendation
Use model output to flag risky applications and suggest improvements before official submission.
